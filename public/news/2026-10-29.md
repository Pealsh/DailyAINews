## 【GitHub】Graphify-Labs/graphify — フォルダ全体をローカルで知識グラフ化するClaude Codeスキル
**日付**: 2026-10-29(週間トレンドで確認) ｜ **⭐ 総数**: 137,763 ｜ **今日**: 不明(週間 +7,268) ｜ **言語**: Python ｜ **最終更新**: 不明

コード・Markdown・PDF・画像が混在したフォルダを渡すと、コードはtree-sitterによる構文解析とコールグラフ、ドキュメントや論文はClaudeによる概念抽出、画像はClaude visionで処理し、中心的な概念や意外なつながりをまとめて報告するClaude Code向けスキル。関係ごとに`EXTRACTED`(抽出)/`INFERRED`(推論)/`AMBIGUOUS`(曖昧)のラベルを付け、どこまでが事実でどこからが推測かを区別できるようにしている。出力は`graphify-out/`フォルダにインタラクティブな`graph.html`、Obsidianボルト、`GRAPH_REPORT.md`、`graph.json`、再実行時に差分だけ処理するためのSHA256キャッシュとして保存される。Neo4jやサーバーなしでローカルで完結する点が特徴で、NetworkX・Leiden(graspologic)・tree-sitter・vis.jsという構成。

### 話題の理由 / 注目度の根拠
週間トレンドで+7,268。「AIに大きなコードベースを読ませる」という作業を、都度生ファイルを読ませるのではなく事前に知識グラフとして構造化しておくことでトークンコストを大きく下げるという具体的な数値(52ファイルの検証で71.5倍)を示している点が評価されている。

### 対象読者
大規模または不慣れなコードベース・ドキュメント群をClaude Codeなどに読ませる前に、構造を事前に把握させたい開発者。

### 今日試せること
```sh
pip install graphifyy && graphify install
# macOSでpipxが必要な場合
pipx install graphifyy
```
```
# Claude Code内で
/graphify .                  # カレントフォルダを解析
/graphify query "..."        # グラフに質問する
/graphify ./raw --watch      # ファイル変更を追従
```
`--mcp`フラグでMCP stdioサーバーとしても起動でき、`graphify hook install`でコミット後にグラフを再構築するgitフックも追加できる。

### 深掘りポイント
`--neo4j`でCypherを生成、`--graphml`でGephi/yEdに書き出せるなど、ローカル完結のデフォルト運用から既存のグラフツールチェーンへ段階的に移行できる設計になっている。「小さなコーパスでは削減効果が小さくなる」と自ら明記している点も、数値をそのまま一般化しないための参考になる。

### 対象読者

- **X(Twitter)**: `x.com`へのWebFetchアクセスがDNS解決不可。WebSearchでも2026年10月28〜29日付の具体的な投稿(反応数・投稿日時付き)を特定できなかったため掲載を見送った。
- **Simon Willison's Weblog**: `simonwillison.net`へのWebFetchアクセスがDNS解決不可。WebSearchでは2026年10月3日付のニュースレター告知記事のみ見つかったが、ブログ本体の直近投稿内容やタイトルは確認できず、具体的な項目として掲載できる情報がなかったため見送った。
- **ニュースレター(TLDR AI / Ben's Bites / The Rundown AI)**: `tldr.tech`等へのWebFetchアクセスがDNS解決不可。WebSearchでも当日号の具体的な項目を特定できなかったため掲載を見送った。
- **GitHub Trending**: `github.com/trending`(daily/weekly)はWebFetch経由でアクセスでき、本記事の★総数・増加数はトレンドページ表示の値をそのまま採用した。`api.github.com`は本セッションのリポジトリアクセス範囲(Pealsh/DailyAINewsのみ)の制約によりHTTP 403で個別リポジトリのメタデータ取得が拒否され、各リポジトリの最終更新日時(pushed_at)は「不明」としている。README本文は`raw.githubusercontent.com`から直接取得して確認した。
- multica-ai/andrej-karpathy-skills(★225,942、単一CLAUDE.mdファイルのみのプロジェクトとしては非常に大きい)など、表示されている★数の正確性自体は検証できていない。いずれもGitHub Trendingページの表示をそのまま転記したもの。
