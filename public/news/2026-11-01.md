## 【GitHub】thedotmack/claude-mem — セッションをまたいでAIエージェントの文脈を自動的に引き継ぐメモリシステム
**日付**: 2026-11-01(本日のデイリートレンド1位で確認) ｜ **⭐ 総数**: 107,738 ｜ **今日**: +1,723 ｜ **言語**: TypeScript ｜ **最終更新**: 2026-10-31

Claude Codeなどのコーディングエージェント向けに、セッション終了後も文脈を保持するための永続メモリシステム。SessionStart/PreToolUse/PostToolUse/Stopなどのライフサイクルフックでツール利用を観測として記録し、ローカルで動くBun製Workerがセマンティックな要約を生成、SQLite(FTS5全文検索)とChromaベクトルDBにハイブリッド検索可能な形で保存する。新しいセッション開始時にはこれらの観測が自動的に読み込まれ、`mem-search`スキルやMCPツール(`search`→`timeline`→`get_observations`の3段階)でオンデマンド検索もできる。Claude Codeを主軸に、OpenCode・T3 Code・Antigravity CLI・Grok Botなど幅広いハーネスに対応する。

### 話題の理由 / 注目度の根拠
本日のデイリートレンド1位で+1,723。「エージェントは毎回ゼロから文脈を説明し直す必要がある」という実務上の不満に対し、フック+ローカルDBという軽量な構成で解決しており、対応ハーネスの広さも支持を集めている。

### 対象読者
長期にわたる同一プロジェクトでClaude Code等を使い続ける開発者。複数のエージェントハーネスを併用していて文脈共有に困っている人。

### 今日試せること
```sh
npx claude-mem install
# Claude Codeのプラグインマーケットプレイス経由でも導入可能
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem
```
インストール後はClaude Codeを再起動するだけで自動的に記憶が働き始める。`npx claude-mem doctor`で導入状態を診断できる。

### 深掘りポイント
`CLAUDE_MEM_SESSION_START_INCLUDE_ALL_SOURCES`を有効にするとCodexなど他ハーネスの観測も起動時コンテキストに含められる点、検索を「圧縮インデックス→詳細取得」の2段にしてトークン削減を主張している設計は、自作のRAG的メモリ機構を作る際の参考になる。ホスト型メモリへのサインインは任意で、`--provider`指定やオフライン設定でスキップ可能。

[リポジトリ](https://github.com/thedotmack/claude-mem)

## 【GitHub】pbakaus/impeccable — LLM不要の62ルールで「AIっぽいUI」を検出するデザイン審査スキル
**日付**: 2026-11-01(本日のデイリートレンドと週間トレンドの両方で確認) ｜ **⭐ 総数**: 98,182 ｜ **今日**: +1,339(週間 +11,323) ｜ **言語**: Rust ｜ **最終更新**: 2026-10-31

コーディングエージェントのUI実装を「もっと洗練させる」「見直す」ための共通のデザイン語彙を提供するスキル。`/impeccable bolder/quieter`で強度調整、`distill`で余計な要素の除去、`colorize`/`typeset`/`layout`で色・文字・配置の修正、`critique`でスコア付きUXレビュー、`audit`でアクセシビリティ・パフォーマンス・レスポンシブ対応をP0〜P3でランク付けした技術レポートを生成する。核心はLLMもAPIキーも使わない62ルールの決定的な判定器で、多用されがちなInterフォント、紫→青グラデーション、入れ子カード、色付き背景上のグレー文字などの「AIスロップ」パターンや見出しレベルの飛びといった品質問題を検出する。CLI(`npx impeccable detect`)はJSON出力やGitHub Actionsのアノテーションにも対応し、Chrome拡張でライブページ上に結果を重ねて表示することもできる。

### 話題の理由 / 注目度の根拠
本日のデイリートレンドと週間トレンドの両方にランクイン。「AIが作るUIはどれも似て見える」という共通の不満に対し、ルールベースで客観的に検出できる仕組みを示したことと、Claude Code・Cursor・Codex・Copilotなど対応エージェントの広さが支持されている。

### 対象読者
AIエージェントにフロントエンド実装を任せているが仕上がりの「AIっぽさ」が気になる開発者・デザイナー。CIでUI品質を自動チェックしたいチーム。

### 今日試せること
```sh
npx impeccable install
# 導入後、ツールを再読み込みしてから
/impeccable init
/impeccable critique the pricing cards
```
CLIだけなら`npx impeccable detect <ディレクトリ or URL>`でも検出結果を確認できる(終了コード2は検出あり、1はスキャン不能)。

### 深掘りポイント
`live`コマンドはブラウザ上で選んだ要素のバリアントをソースファイルに直接書き換える点、デフォルトでテレメトリが有効でimpeccable.styleのカタログからデザイン方向性を取得・匿名記録する点は、未知のリポジトリで使う前に確認しておきたい。62ルールの判定器自体を読むと「AIっぽいUI」を定量的に定義する試みとして参考になる。

[リポジトリ](https://github.com/pbakaus/impeccable)

### 対象読者

### 深掘りポイント
`ATTACK-CLASSES.md`など監査クラス別のファイルを分けている設計や、`validate-findings.cjs`/`validate-coverage-ledger.cjs`によるスキーマ検証の仕組みは、LLMの出力を構造化データとして品質管理する実践例として読む価値がある。同じリポジトリに繰り返し実行すると前回の結果に追記され、変更箇所だけ再チェックされる差分運用も特徴。

## 【Simon Willison】Anthropic、「Agent Skills」標準をMCPと同じAgentic AI Foundationへ寄贈
**日付**: 2026-10-22(投稿/Anthropic発表)

Simon Willisonのリンクブログが、AnthropicがAgent Skills標準をAgentic AI Foundation(AAIF)に寄贈したという発表を紹介している。AAIFはAnthropicがBlock・OpenAIと共同設立したLinux Foundation傘下の組織で、以前にMCP(Model Context Protocol)もここに寄贈されている。今回の寄贈対象はAgent Skillsの名称・ロゴ・GitHub organization・agentskills.ioドメインで、AAIFに参加しなくても標準の利用・貢献は続けられるとAnthropicは説明している。発表はAGNTCon + MCPCon North Americaの場で、AAIFが追加する4つの新プロジェクトの一つとして行われた。既存のSKILL.mdファイルは書き換えなしで使い続けられる。

### 話題の理由 / 注目度の根拠
サードパーティ製Agent Skillsが急増している最中に、仕様の「ベンダー中立化」が公式に決まったというガバナンス上の大きな節目。MCPと同じ非営利団体に置かれることで、エージェント相互運用性の仕様が一つの団体に集約されていく流れが明確になった。

### 対象読者
自作Skillを公開・配布している開発者。企業で複数ベンダーのエージェントにSkillsを導入しようとしている技術リード。

### 今日試せること

### 深掘りポイント
MCPとAgent Skillsが同じAAIFに集約されたことで、今後両仕様の互換性・改訂プロセスがどのように揃えられていくかが注目点。Skillを公開している開発者は、AAIFのガバナンス文書(GitHub organization移管時の規約)を一度確認しておくとよい。
