## 【GitHub】Usagi-org/ai-goofish-monitor — AIが条件判定する「闲鱼(中国版フリマ)」自動監視エージェント
**日付**: 2026-11-06時点で日間トレンド確認 ｜ **⭐ 総数**: 約17.5k ｜ **今日**: +242(日間トレンド) ｜ **言語**: 不明(Python/Node.jsが混在、GitHub上のLanguages欄は非表示) ｜ **最終更新**: 不明

ai-goofish-monitorは、PlaywrightによるブラウザAIエージェントと画像対応LLMを組み合わせ、中国最大のフリマアプリ「闲鱼(Xianyu)」の商品を常時/定期監視するMITライセンスのOSSである。ユーザーがキーワードや価格帯だけでなく「状態が良くて即購入可能なものだけ」といった自然言語の条件を設定すると、AIが各商品の画像とテキストを基に推奨すべきかを判定する「AI判断モード」を備える。Webの管理UIからタスク・アカウント・プロンプトの管理、実行ログの確認ができ、ntfy.sh・企業微信・Bark・Telegram・Webhookなど多数の通知先に対応する。複数アカウントの併用やプロキシのローテーション、失敗時のリトライも組み込まれており、Docker Composeでの一括デプロイが推奨されている。

### 話題の理由 / 注目度の根拠
本日のGitHub日間トレンドでAI関連として上位(+242★)。「AIエージェントに実際の購買判断を一部委ねる」という具体的でわかりやすい用途が支持されているとみられる。一方で第三者の解説記事(knightli.com)は、検索結果の変化やログイン状態の失効、プラットフォーム側のリスク管理によって安定性が損なわれる可能性を指摘し、「全自動で掘り出し物を拾う道具ではなく補助的な絞り込みツール」として使うよう注意している。

### 対象読者
中国のフリマ・せどり市場でAIによる商品監視を試したい個人開発者、Playwright+AIを組み合わせた監視エージェントの実装パターンに興味があるエンジニア。

### 今日試せること
```sh
git clone https://github.com/Usagi-org/ai-goofish-monitor.git
cd ai-goofish-monitor
# OpenAI互換のAPIキー・エンドポイント(画像入力対応モデル)を.envに設定
# Chrome拡張で闲鱼のログイン状態をJSONとして書き出して配置
docker compose up -d --build
```

### 深掘りポイント
闲鱼へのログインが切れた場合の運用(セッション再取得の手間)や、プロキシローテーションがどの程度アカウント停止リスクを下げられるかは、READMEやIssue(本稿執筆時点で複数件オープン)で実際の利用者の声を確認する価値がある。

[リポジトリ](https://github.com/Usagi-org/ai-goofish-monitor)

## 【GitHub】google/skills — Google公式のAgent Skillsライブラリ、GCPスキルをコマンド一発で導入
**日付**: 2026-11-06時点で日間トレンド確認(リポジトリ自体は2026年4月公開) ｜ **⭐ 総数**: 約22.3k ｜ **今日**: +199(日間トレンド) ｜ **言語**: 不明(Languages欄非表示) ｜ **最終更新**: 不明

google/skillsは、GoogleがApache-2.0ライセンスで公開するGoogle Cloud関連の公式Agent Skills集である。BigQuery・Cloud Run・Cloud SQL・AlloyDB・Firebase・GKE・Gemini API(Agent Platform)などプロダクト別のスキルに加え、認証設定やオンボーディング、Well-Architected Frameworkの6本柱に沿った助言を行う「レシピ」スキルを含み、100を超えるスキルが揃う。導入は`npx skills add google/skills`で対象スキル・対象エージェント・インストール範囲(プロジェクト/グローバル)を選ぶ方式と、Claude Code/Codex/Antigravity CLI向けのプラグインマーケットプレイス経由のどちらかを選べる。Android・Dart・Firestore・Flutter・Google Maps向けなど関連リポジトリも別途公開されている。

### 話題の理由 / 注目度の根拠
4月公開以来着実に star を積み重ね、本日も日間トレンドに入るなど成長が継続している。8月時点の報告では「1万5千★超、構築・テスト・ガバナンス方法を公式に説明」という記事もあり、GoogleがAgent Skillsのエコシステムで存在感を強めている点が注目されている背景とみられる。

### 対象読者
Google Cloud上でAIエージェント(Gemini CLI・Claude Code等)を運用し、BigQueryやCloud Runなど個別プロダクトの定型作業をエージェントに任せたいインフラ・データエンジニア。

### 今日試せること
```sh
npx skills add google/skills
# 対話形式でスキル(例: BigQuery, Cloud Run)・対象エージェント・導入範囲を選択
npx skills update  # 既存スキルの更新・不要スキルの削除提案
```

### 深掘りポイント
各スキルがどのGCP権限(IAMロール)を前提に動作するか、Agent Platform(旧Vertex AI)向けスキルがGemini 3系モデルの機能拡張にどこまで追従しているかは、個々のスキルのSKILL.mdを読んで確認する価値がある。

[リポジトリ](https://github.com/google/skills)

## 【GitHub】ConardLi/garden-skills — Web制作・文書検索・画像生成をまとめた個人開発者発のSkill集
**日付**: 2026-11-06時点で日間トレンド確認 ｜ **⭐ 総数**: 約14.1k ｜ **今日**: +241(日間トレンド) ｜ **言語**: 不明(大半がMarkdown、一部TypeScript/React) ｜ **最終更新**: 不明

garden-skillsは、個人開発者ConardLiが公開するMITライセンスのAgent Skills集で、Web制作・ローカル知識検索・画像生成を中心に構成される。`web-design-engineer`はランディングページやダッシュボードのプロトタイプ作成を支援し、25種の「style recipe」と設計方針アドバイザーを内蔵する。`kb-retriever`はローカルの`knowledge/`フォルダ(Markdown・テキスト・PDF・Excel)を最大5回の検索ラウンドで調べ、出典を明示して回答する。`gpt-image-2`はGPT Image 2やOpenAI互換APIでの画像生成・編集向けに79種のプロンプトテンプレートと3つの実行モードを備える。Claude Code・Claude.ai・Cursor・Codex CLI・Gemini CLI・OpenCodeで動作確認済みとされる。

### 話題の理由 / 注目度の根拠
本日の日間トレンドで+241★。Agent Skillsの「公式リポジトリ」ではなく個人開発者が実務で使うスキルを公開・継続更新している点、複数の主要コーディングエージェントで動作確認済みと明記している点が、実際に使えるかどうかを重視する開発者から支持されているとみられる。

### 対象読者
Claude Code/Cursor等でランディングページ作成やローカル文書への質問応答、画像生成を自動化したいフロントエンド・コンテンツ系エンジニア。

### 今日試せること
```sh
npx skills add ConardLi/garden-skills -s web-design-engineer -a claude-code
# Claude Codeプラグインマーケットプレイス経由の場合
# /plugin marketplace add ConardLi/garden-skills
# /plugin install web-design-skills@garden-skills
```

### 深掘りポイント
`kb-retriever`の「最大5回の検索ラウンド」という制約が大規模なナレッジベースでどこまで回答精度を保てるか、`gpt-image-2`の79種プロンプトテンプレートが実際の生成品質にどれだけ寄与するかは、自分のユースケースで試して確認する価値がある。

[リポジトリ](https://github.com/ConardLi/garden-skills)

## 【GitHub】The-PR-Agent/pr-agent — GitHub Action/CLIから動くオープンソースAI PRレビューエージェント
**日付**: 2026-11-06時点で週間トレンド確認 ｜ **⭐ 総数**: 約15.1k ｜ **今日(週間)**: +966 ｜ **言語**: 不明(pyproject.toml・pytest等からPythonと推定) ｜ **最終更新**: 不明

PR-AgentはMITライセンスで公開されているAI PRレビューエージェントで、「The Original Open-Source PR Reviewer」を名乗り、商用版を提供するQodoとは別のコミュニティ主導プロジェクトとして運営されている。GitHub・GitLab・Bitbucket・Azure DevOps・Gitea上でPRコメントまたはCLIから`/describe`(PR概要生成)・`/review`(レビュー)・`/improve`(改善提案)・`/ask`(自由質問)・`/similar_issue`(類似issue検索)といったツールを呼び出せる。各ツールは1回のLLM呼び出しで完結し、大きなPRにも対応するための圧縮戦略を採用。対応モデルはOpenAI GPT・Anthropic Claude・Google Gemini・DeepSeek・Mistralに加え、LiteLLM経由でAzure OpenAI・AWS Bedrock・Vertex AI・Ollama等も利用できる。

### 話題の理由 / 注目度の根拠
直近1週間で+966★と週間トレンドに入った。AIによるPRレビュー自動化という実務ニーズが高いテーマに加え、マルチプロバイダ・マルチGitホスティング対応という汎用性の高さが評価されているとみられる。なお`/help_docs`コマンドは資格情報露出に関する問題のためv0.36.1以降一時的に無効化されている点は留意が必要。

### 対象読者
自社のCI/CDパイプラインにAIレビューを組み込みたいが、特定ベンダーにロックインされたくないプラットフォーム・DevOpsチーム。

### 今日試せること
```yaml
# .github/workflows/pr_agent.yml
on:
  pull_request:
    types: [opened, reopened, ready_for_review]
  issue_comment:
jobs:
  pr_agent_job:
    runs-on: ubuntu-latest
    steps:
      - name: PR Agent action step
        uses: the-pr-agent/pr-agent@main
        env:
          OPENAI_KEY: ${{ secrets.OPENAI_KEY }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

### 深掘りポイント
`/help_docs`が無効化される原因となった資格情報露出issueの詳細、および自組織のLLMプロバイダ(Bedrock/Vertex AI等)をLiteLLM経由でどこまで細かく設定できるかは、公式ドキュメントとIssueトラッカーで確認する価値がある。

[リポジトリ](https://github.com/The-PR-Agent/pr-agent)
